# Security reporting

Please report security problems privately through GitHub's **Security → Advisories → Report a vulnerability** form if it's available. If you don't see it, ask the maintainer for a private channel without posting the details in a public issue.

Use made-up calendar data in your report. Leave out your Apple sign-in, passwords, media feed URLs, weather keys, real calendar exports, and private screenshots. The [README](README.md#security-and-privacy) explains what Kalends reads, where it sends data, and what it can change.
